# Support

Read the `README.md` first.

| You need | Go to |
|---|---|
| An answer or an idea | [Discussions](https://github.com/revenantworks/godot-pixel-fx/discussions) |
| To report a bug or ask for a feature | [New issue](https://github.com/revenantworks/godot-pixel-fx/issues/new/choose) |
| To report an accessibility barrier | [New issue](https://github.com/revenantworks/godot-pixel-fx/issues/new/choose), "Accessibility barrier" |
| To report a security problem | [Private form](https://github.com/revenantworks/godot-pixel-fx/security/advisories/new) |

Do not paste secrets, real names, personal paths, or email addresses into any public space.
