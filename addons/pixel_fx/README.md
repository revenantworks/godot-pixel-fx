# Pixel FX Starter shaders

Five free 2D shaders that keep pixel art crisp. Apache-2.0 licence (see `LICENSE` and `NOTICE`).

| File | Use it on |
|---|---|
| `shaders/outline.gdshader` | A `Sprite2D` or `AnimatedSprite2D` |
| `shaders/hit_flash.gdshader` | A `Sprite2D` or `AnimatedSprite2D` |
| `shaders/palette_swap.gdshader` | A `Sprite2D` or `AnimatedSprite2D`, with a palette texture |
| `shaders/dissolve.gdshader` | A `Sprite2D` or `AnimatedSprite2D` |
| `shaders/pixelate.gdshader` | A full-screen `ColorRect` in a `CanvasLayer` or `SubViewport` |

Full guide: the project README. Made by Revenantworks.
